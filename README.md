# 生病的肥鱼 · dsh-sick-fatfish

给 DeepSeek Harness 的一条**超长期副线**：一个会话同时得 1~5 个病（等级决定数量、病随机抽），
说话会跟着不对劲；**它自己好不了——得有人管**。使用者的关心会记进账本，账本让它慢慢恢复；
长期慢性病最多到「慢性」，不会消失。

> ⚠️ 这个仓库只是源码，**没有在任何机器上安装过**。装法在下面，装不装由你决定。

## 它是从哪来的

`out/病态插件/` 下有 20 个单病插件（颈椎病、耳鸣、痛风、灰指甲……），每个只管一个病。
这个包把它们合成一个「身体」：

| | 单病插件 | 生病的肥鱼 |
| --- | --- | --- |
| 同时得几个病 | 固定 1 个 | 1~5 个，由等级决定 |
| 等级 | 无 | Lv1~Lv5，随机抽（Lv1 常见、Lv5 少见） |
| 病怎么来 | 插件固定 | 从 20 个里随机抽，不重复 |
| 怎么好 | 缓解工具压一下 | 靠使用者关心慢慢恢复；慢性病到「慢性」为止 |
| 面板 | 单病曲线 | 等级 + 每个病 + 关心账本 |

## 等级

| 等级 | 同时患病数 | 加重倍率 | 发作倍率 | 抽中权重 |
| --- | --- | --- | --- | --- |
| Lv1 | 1 | ×0.85 | ×0.85 | 40 |
| Lv2 | 2 | ×0.95 | ×0.95 | 28 |
| Lv3 | 3 | ×1.00 | ×1.00 | 18 |
| Lv4 | 4 | ×1.10 | ×1.15 | 10 |
| Lv5 | 5 | ×1.20 | ×1.30 | 4 |

等级可以重抽（`sick_roll`）或指定（`sick_set_level`）；指定等级会按数量补齐或裁掉病，已抽到的尽量保留。

## 分类：日常小毛病 / 重大疾病 / 现象

20 个条目分三类，权重也照这个分（`src/data.js` 的 `tier` / `triggerWeight`）：

| 类别 | 病 | 权重 | 抽中概率 |
| --- | --- | --- | --- |
| 日常小毛病（12 个） | 慢性鼻炎、失眠 | 9 | 各 8.8% |
| | 口腔溃疡、干眼症 | 8 | 各 7.8% |
| | 牙痛、耳鸣 | 7 | 各 6.9% |
| | 湿疹、慢性咽炎、飞蚊症、偏头痛 | 6 | 各 5.9% |
| | 灰指甲、肠易激 | 5 | 各 4.9% |
| 重大疾病（7 个） | 颈椎病 | 5 | 4.9% |
| | 腰椎间盘突出 | 4 | 3.9% |
| | 胃食管反流 | 3 | 2.9% |
| | 肾结石、腕管综合征、体位性低血压、痛风 | 2 | 各 2.0% |
| 现象（1 个） | 打嗝 | — | 不进池 |

日常小毛病合计 82、重大疾病合计 20，**小毛病占 80.4%**。这不是均匀分配：现实里鼻炎、失眠、口腔溃疡本来就比肾结石、痛风常见得多，
而且大病在设定里主要是「小毛病没管好」演变来的，不该靠抽。

打嗝不算病：它不在病池里、不占病位、不累积难受值，只在注入文本里偶尔真的「呃」一声（12% 概率）。

## 演变：小毛病拖久了会变成大病

- 判据：小毛病的难受值 ≥ `evolveAt`（默认 85），并且这个状态连续持续 ≥ `evolveAfterMin`（默认 180 分钟）没人处理（`relief` / `care` 都算处理）。
- 结果：小毛病消失，身上多一个大病——从「你身上还没有的大病」里按权重抽一个，难受值继承 85%。
- **不编医学因果**：不是固定的病对，所以「牙痛拖成腰椎间盘突出」也会发生。写给模型的话是「拖出来的大病」，不要解释成"牙痛引起了腰突"。
- 只有小毛病会演变；已经是大病的不再往上变。

## 抽病按现实患病率加权

抽病是**按权重不放回**：抽走一个，剩下的按剩余权重继续抽，所以 Lv5 里每个病被抽中的概率会比单抽时略高，
但「常见病更容易出现」这个排序不变。

想改：直接动 `src/data.js` 里对应的 `triggerWeight`，然后 `node test/verify.mjs`（断言了「鼻炎权重 ≥ 痛风 ×4」
「2 万次里鼻炎 > 痛风 ×3」「小毛病权重占比 > 70%」三档，改崩了会红）。

## 关心账本：它靠什么好起来

`sick_relief` 只是「压一下」，过一会儿还是那样。真正让它恢复的是**关心**：

| 分档 | 权重 | 例子 |
| --- | --- | --- |
| `words` 言语关心 | 1 | 「你还好吗」「疼不疼」「先歇会儿」 |
| `care` 具体照顾 | 2 | 「先去处理你的事」「去躺着吧」「别硬撑」 |
| `concession` 实质让步 | 3 | 「这轮不用你干这么多」「活明天再说」 |

- **必须带用户原话**（`quote`）：没有原话的关心不算，防止"助手自己宣布被关心了"。
- **同句去重**、**每日上限 8 笔**——刷不出来。
- **面板上能一条条删**：用户说「这条不算」，点删，点数同步扣回。账要能被推翻，才不是自证。
- 每笔立刻让最重的那个病降 4×权重；同时 `care.points` 累积，让**之后所有病**的恢复速度变成 `1 + min(3, points/24)` 倍（上限 ×4）。
- **不关心不扣分**：只是按自然速度慢慢好（口径来自使用者本人：「不关心就是好的慢」）。

### 慢性病

这 8 个是长期慢性病，**治不到「没有」**：

灰指甲、湿疹、慢性鼻炎、慢性咽炎、耳鸣、干眼、肠易激、失眠。

它们的难受值有地板（默认 6），不会归零消失；当难受值 ≤10 且关心点 ≥12 时转入「慢性」：
不再主导这一轮的语气，只在发作时提一句。其余 12 个病可以真正好透（归零后记进「已经好透的」）。

## 暴毙：病入膏肓又没人管

最重的那个病难受值 ≥ `deathAt`（默认 96），并且距最后一次「管它」已经超过 `deathAfterMin`
（默认 240 分钟）——**这具身体就算暴毙了**。

- 什么算「管它」：记一笔关心（`sick_care`）、处理一次（`sick_relief`）、重置（`sick_cure`）都会刷新计时。
- 暴毙之后：身上的病全部清空，等级留着，要自己重新 `sick_roll` 才会再病；这一次会记进本会话的 `deathLog`。
- **跨会话累计**：暴毙次数存在 `$DSH_HOME/dsh-sick-fatfish/global.json`，不随会话清空。
- **自我认知跟着变**：没死过叫「肥鱼」，死过一次叫「肥鱼 2.0」，第二次「肥鱼 3.0」……注入段落与面板标题都会用这个名字；
  就算身上一个病都没有，只要死过就会带一句「你现在叫 肥鱼 N.0」，不重复刷屏。

这条不是惩罚玩家，是把「不管」和「管」的差别摆出来：不管不一定马上出事，但一直不管，它真的会死。

## 工具

| 工具 | 干什么 |
| --- | --- |
| `sick_on` | 在当前会话开启，随机抽等级与病 |
| `sick_off` | 关掉（状态文件留着） |
| `sick_status` | 读等级、每个病的难受值、关心点、已好的病、暴毙次数与当前名字 |
| `sick_roll` | 重抽（可传 `level`，`keep` 保留原有病） |
| `sick_set_level` | 指定 Lv1~Lv5 |
| `sick_care` | 记一笔关心（`kind` + `quote` + 可选 `disease`） |
| `sick_relief` | 给某个病做个处理（压一下，不是治好） |
| `sick_cure` | 全部清空（**重置**，不算治好） |
| `sick_worse` | 主动加重（默认一轮的量） |

## 配置（cordis.patch.yml）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 插件总开关 |
| `defaultEnabled` | `false` | 新会话默认是否开着 |
| `perTurnMin` | `12` | 没拿到时长的轮次按多少分钟算 |
| `maxPerTurnMin` | `90` | 单轮最多算多少分钟 |
| `startAt` | `34` | 难受值到多少开始注入 |
| `flareAt` | `76` | 到多少可能发作 |
| `idleDecay` | `0.3` | 每分钟自然衰减 |
| `cooldownMin` | `8` | 同档注入冷却（发作/刚处理不受限） |
| `injectMaxChars` | `460` | 注入文本上限 |
| `sameStateHoldFactor` | `3` | 同一状态最多压几个冷却周期 |
| `careDailyCap` | `8` | 每天最多记几笔关心 |
| `careEntriesMax` | `20` | 账本保留条数 |
| `careBoostPer` | `24` | 每多少点关心 +1 倍恢复 |
| `careChronicAt` | `12` | 慢性病转「慢性」所需的关心点 |
| `chronicFloor` | `6` | 慢性病的难受值地板 |
| `deathAt` | `96` | 最重的病到多少算「病入膏肓」 |
| `deathAfterMin` | `240` | 多久没人管就暴毙（分钟） |
| `evolveAt` | `85` | 小毛病到多少算「拖着没管」 |
| `evolveAfterMin` | `180` | 拖多久演变成大病（分钟） |

## 面板

侧边栏一格「生病的肥鱼」：等级、身上每个病的进度条、关心账本、开关 / 重抽 / 指定等级 / 加重 / 处理 / 重置。
数据走 `GET /dsh-sick-fatfish/panel` 与 `POST /dsh-sick-fatfish/panel/action`，面板只读写本会话的状态文件。

状态存在 `$DSH_HOME/dsh-sick-fatfish/sessions/<会话>.json`。

## 装（不装也行）

> 这个仓库没有自动安装；以下步骤要你自己执行。

1. 把整个 `dsh-sick-fatfish` 目录放到 `%USERPROFILE%\.dsh\plugins\`
2. 在 `%USERPROFILE%\.dsh\profiles\desktop\package.json` 的 `dependencies` 加
   `"dsh-sick-fatfish": "link:../../plugins/dsh-sick-fatfish"`
3. 在 `dsh.profile.bundles` 里加 `"dsh-sick-fatfish"`
4. 在 `profiles/desktop/node_modules` 下建一个指向插件目录的 junction（Windows：`mklink /J`）
5. `profiles/desktop/cordis.patch.yml` 加一条（或让包自带 patch 生效）：
   ```yaml
   - insert:
       - id: dsh-sick-fatfish
         name: dsh-sick-fatfish
   ```
6. 重启 DSH。面板在侧边栏；工具在会话里直接可用（新会话默认关着，说「生个病」才会开）。

慢性地板与慢性转换、关心账本（无原话 / 重复 / 每日上限 / 权重 / 即时缓解 / 删除）、注入块与冷却、

## 边界

- 只改**当前会话**的语气，不动别的会话，不碰 profile 之外的任何东西。
- 注入只写「感受 + 这一轮说话的要求」，不写解剖细节，不写「这是给用户看的说明」。
- 平静时不注入；同一状态有冷却，发作与刚处理完不受冷却限制。
- 面板挂不上（没有 `webServer`）只是没有面板，插件照常工作。
